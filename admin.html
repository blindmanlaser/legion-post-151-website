How to get an editor key (one time)
  1. Sign in to GitHub as blindmanlaser and open New fine-grained token.
  2. Name it Post 151 site editor and pick an expiration (up to a year).
  3. Under Repository access, choose Only select repositories and pick legion-post-151-website.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it above. Treat it like a password: it can only change this website.
